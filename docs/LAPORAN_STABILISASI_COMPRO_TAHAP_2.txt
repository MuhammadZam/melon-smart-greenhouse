D. Deduplikasi

SHA-256 dari namespace v2 + device_id + observation_id adalah PK
identity_hash ledger. Fingerprint membandingkan tanaman, instan waktu
yang dinormalisasi ke UTC hingga mikrodetik, dan tiga sensor kanonik.
Transaksi membuat receipt sebelum menulis monitoring, alarm atau
inferensi. Klien replay mendapatkan ID rekaman pertama; kanal pertama
menentukan source dan metadata. Konflik memberi 409 di API dan baris
gagal di Sheets. Klien legacy memakai identitas versi lama per kanal.
Uji MySQL dengan sembilan worker API dan satu worker Sheets mock
menghasilkan satu rekaman, satu receipt, satu alarm dan satu inferensi.
